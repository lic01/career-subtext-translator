## 文件结构
- `index.html` — 前端页面（v4.1 四卡片 UI + **场景/阶段胶囊点选** + 分享图生成 + 演示模式）
- `config.js` — 前端代理地址配置
- `server.js` — Node 代理：托管前端 + `/api/translate` 调用 Coze（零依赖，内置 Bot ID，仅 PAT 走环境变量）

## 一、获取 Coze 凭证（必做）
1. 打开智能体编辑页 → 右上角【发布】→ 渠道勾选 **API** → 发布（换提示词后必须重新发布，否则调到的仍是旧逻辑）。
2. 地址栏 `https://www.coze.cn/space/.../bot/xxxxxxxx` 末尾数字串即 **Bot ID**（本项目已内置：`7665697678680047642`，无需再填）。
3. 左侧菜单「API 管理」→ 顶部 Tab 点「授权」→ 子 Tab「个人访问令牌」→「添加」（权限至少勾 `chat`，有效期按上限选）→ 复制 **PAT**（只显示一次，务必保存）。直链：`https://www.coze.cn/open/oauth/pats`

## 二、本地运行（最快验证）
```bash
cd 潜台词翻译器H5
COZE_PAT=你的pat node server.js
# 浏览器打开 http://localhost:3000
```
- `COZE_BOT_ID` 已内置，无需设置；如需覆盖再传 `COZE_BOT_ID=xxx`。
- 未设置 `COZE_PAT` 时，前端自动进入「演示模式」（用内置样例渲染，方便先看 UI / 截图）。

## 三、公开部署（给粉丝用，必须服务端代理，不能把 PAT 写前端）
### 方案 A：Vercel（推荐，免费层够用）
1. 把本目录推到 GitHub，在 Vercel 导入。
2. 在项目 Settings → Environment Variables 添加 `COZE_PAT`（Bot ID 已内置，无需加 `COZE_BOT_ID`）。
3. Vercel 会自动用 `server.js` 作为服务（Node 运行时）。部署后得到 `https://xxx.vercel.app`。

### 方案 B：腾讯云函数 / 任意 Node 服务
- 上传 `server.js` + 静态文件，设置环境变量 `COZE_PAT`，监听 `PORT`。

### 前端接代理
- 若前端独立部署（如 CloudStudio 静态站），把 `config.js` 里的 `PROXY_URL` 改为你的代理公网地址：
  ```js
  window.APP_CONFIG = { PROXY_URL: 'https://xxx.vercel.app' };
  ```
- 若前端由 `server.js` 同源托管（本地或 Vercel 同仓），`PROXY_URL` 留空 `''` 即可。

## 四、重要红线
- **PAT 永远只放服务端环境变量**，前端代码里不留任何密钥。
- 潜台词内容天然敏感，提示词已校准为「揭示现象 + 正向应对」，上线前请自测几条避免踩「煽动对立 / 影射」合规红线。
- 微信小程序对**个人主体不开放 AI 问答类目**，如需小程序需企业资质或走「小微智能体」壳；H5 无此限制，可先跑。
